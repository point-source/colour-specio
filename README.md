# Specio

Specio is a python library for interacting with spectrometers. The Colorimetry
Research family is supported, and particularly this library is tested and
maintained with a CR300. Photo Research PR-655/670 spectroradiometers are
supported in remote mode, tested with a PR-655.

This library also provides a virtual spectrometer which provides semi-random
SPDs as measurements.
